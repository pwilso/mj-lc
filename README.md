# Multijunction Luminescent Coupling (MJ-LC): Advanced Luminescence

## Description
This project calculates the coupling matrix needed to implement luminescent coupling into an electro-optical simulation. The coupling matrix relates a radiative recombination event in a semiconductor device to an absorption events elsewhere in the device. It performs this calculation using the transfer matrix method (TMM) with the fields being generated internal to the layer stack. This calculation is performed using Python.

The project also contains supporting files to help the user integrate the tools into a Synopsis Sentaurus project.
