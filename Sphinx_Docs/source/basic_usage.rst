Basic Usage
===================================

This project consists of three main files that perform the TMM calculations and a handful of tools for plotting the outputs. These three files are:

**LC_Matrix.py**: This file is the main file the user will interact with. There is a header section (described below) where the user will enter all the information needed to control the inputs and outputs of the code.

**epi_cmd_LC.pyx**: Written in Cython, this file sets up the epitaxial layer structure for the calculation and extracts information about the materials. The average user should not need to change anything within this file.
*N.B. This project was originally designed for use with Synopsys Sentaurus. As such it currently require epi, matpar, and sde files produced by Sentaurus to set up the structure.*

**tmm_mw.pyx**: Written in Cython, this file performs many of the functions required for the TMM calculation. The average user should not need to change anything within this file.

Set-Up
----------------------------------

The header section of LC_Matrix.py is as follows:

.. code-block:: python

  ### USER INPUT ################################################################ #!!!
  run_method = "CMD_or_TCL"
  Pooling = True
  Threading = True

  use_gaussian_quadrature = False

  test_integral_z = 'z_loop_calc_a'
  n_angles = 40
  n_energies = 30
  include90atend = True

  # should be relative to the project directory
  matrix_file = 'LC_Outputs/LC_Python.csv'
  h5_filename = 'LC_Outputs/LC_Python.h5'

  # what kind of data do you want to be output?
  # LC_out = True # output the LC coupling matrix
  # abs_out = True # output the absorption matrix
  # abs_th_E = True # output the absorption integrated in two different ways
  # Efield_out = True
  # TMM_out = True # output a bunch of TMM data
  write_TMM = False # write the TMM data to the h5 file
  write_pos = False # write the position resolved data to the h5 file

  # these only need to be set if run_cmdline is true
  epi_node = 123
  sde_node = 456
  MatPar_node = 789
  wtot = 1.0
  substrate_t = 0.5 # 0.0 to include a flat Au back reflector

The user inputs perform control the following:

**run_method**

This code can be run from the command line or from within Sentaurus. There are two methods of running from within Sentaurus: using the workbench Python tool or using a TCL script. If running from a Python workbench tool then this variable should be set to "Sentaurus." If running from either the command line or from a Sentaurus TCL script then it should be set to "CMD_or_TCL." And lastly if running from a Python IDE then "Py_IDE" can be selected. These options ensure that the correct paths are specified as the working directories will change depending on where the code is running.

.. warning::
  At this point in time running LC_Matrix requires some input files that are generated by a Sentaurus project. These files are generated from the epi, matpar, and sde nodes of Synopsys Sentaurus and provide information about the layer structure and refractive indices throughout the device. If you intend to run from the command line but are working with a Sentaurus project the easiest way to handle this is to run the program from the same location as the Sentaurus "results" folder and then supply the required node numbers at the end of the User Input section.

  If you are not intending to work with Sentaurus, a "dummy" Sentaurus file will need to be created that mimics the structure of the Sentaurus project. In the future, a new file format may be added to generalize the process.

**Pooling**

If True, allows the code to run in parallel.

**Threading**

Not recommended to be changed. Will likely be removed.

**use_gaussian_quadrature**

If True, the integration over the angular component is done using guassian quadrature. If False, the integral is done using the trapezoidal rule and linearly spaced angles.

**test_integral_z**

Not recommended to be changed. Will likely be removed.

**n_angles**

The number of angles to be used. Will be spaced linearly if use_gaussian_quadrature is False or will be spaced and weighted accordingly if use_gaussian_quadrature is True. The bounds of the angles are [0, :math:`{\pi}`/2) (*Note: user can select whether or not to explicitly include :math:`{\pi}`/2 at the end by setting* include90atend.)

**n_energies**

The number of energies to be used. Will be spaced linearly in energy. The limits are [E\ :sub:`g` \, E\ :sub:`g` \ + 10*300*k\ :sub:`b` \) where E\ :sub:`g` \ is the bandgap of the material and k\ :sub:`b` \ is the Boltzman constant. The bandgap is assumed to be that at 300 K.

**include90atend**

Append :math:`{\pi}`/2 to the end of the list of angles. Depending on how tightly spaced your angle list is, and whether you are using a guassian quadrature spacing or not, this may not be needed.

**matrix_file**

The name of the matrix file which is output. This is a csv file. The matrix will be located relative to where LCMatrix_pyt.py is run. *Note: this only applies if you are running from the command line. If running from within Sentaurus the naming convention is set based on a Sentaurus project variable.*

**h5_filename**

You may choose to output all the data as an h5 file (see the **write_TMM** and **write_pos** variables), if either of these are True then this is the name of the file that is produced. It is located relative to where LCMatrix_pyt.py is run. This will include all the data contained in the matrix_file.csv as well as some extra values (for example the electric fields at specific angles and energies.)

.. warning::
  The h5 file that is produced can be useful for "deconstructing" the LC matrix or for debugging but it can also produce an extremely large file. I don't recommend setting this True unless you are prepared to deal with GB of data or you are running on a very sparse mesh.

**write_TMM**

If True write the outputs of the TMM calculation. This will include values such as the forward and backward electric fields as a function of angle and position at the boundaries of each layer in the device.

**write_pos**

If True write the outputs of the position dependent calculation. This will include values such as the forward and backward electric fields as a function of angle and position as well as various integrated quantities at each mesh point in the device. This has the potential to create a very large file.

**epi_node**

The number associated with the folder where the Sentaurus epi files are stored. This folder should be located in a results/# folder that is relative to the working directory. This is ignored if you are not running from the command line.

**sde_node**

The number associated with the folder where the Sentaurus device files are stored. This folder should be located in a results/# folder that is relative to the working directory. This is ignored if you are not running from the command line.

**MatPar_node**

The number associated with the folder where the Sentaurus material files for the specific project are located (this is different than the par and pardb folders.) This folder should be located in a results/# folder that is relative to the working directory. This is ignored if you are not running from the command line.

**wtot**

The width of the device. If equal to 1.0 this implies a 1D device calculation (width is normalized to 1 :math:`{\mu}` m.)

**substrate_t**

The thickness of the substrate (or last layer of the device.) Technically, the last layer in the calculation has semi-infinite thickness. This variable specifies the bottom layer in the Sentaurus project. If it is equal to 0.0, then a semi-infinite layer of gold is set as the last layer in the TMM calculation to simulate a planar back-reflector. If the value is finite then this is the thickness of the last finite layer in the Sentaurus project. A semi-infinite layer of InP **(!!!)** will be appended to the end of the layer stack in the TMM calculation. Additional layers can be added by setting the **back_mat (!!!)** list.

The PMI Interface (Working with Sentaurus)
------------------------------------------

The python program LCMatrix_pyt.py produces the coupling matrix which will be read by Sentaurus using the custom physical model interface: OpticalCoupling_Recombination.
OpticalCoupling_Recombination is implemented in Sentaurus through a C++ file compiled using Sentaurus' CMI compiler.
The g++ compiler used by Sentaurus to compile its tools must match the compiler used by CMI exactly. For example, version vS_2021.06 works with g++ 9.2.0.
To properly compile OpticalCoupling_Recombination.so.arch follow these steps:

#. |
   | Check the compiler version. Run:
   .. code-block:: bash

    cmi -a

   | The g++ versions must match exactly.

#. | If they don't match you'll need the correct compiler. Check devtoolset to see if the exact compiler is available. Otherwise follow the below instructions to make the compiler from source (change versions accordingly):
   .. code-block:: bash

    wget https://ftp.gnu.org/gnu/gcc/gcc-9.2.0/gcc-9.2.0.tar.gz
    tar -xvf gcc-9.2.0.tar.gz
    mkdir obj.gcc-9.2.0
    cd gcc-9.2.0
    ./contrib/download_prerequisites
    cd ../obj.gcc-9.2.0
    ../gcc-9.2.0/configure --prefix $HOME/.local --disable-multilib --enable-languages=c,c++

   | *Note*: setting --prefix points to where the install will be located, in this case it is installed on a local user account
   .. code-block:: bash

    make -j 8

   | *Note*: setting -j sets the number of cores used during make, -j 8 took approximately 1 hr but will depend on the machine
   .. code-block:: bash

    make install

#. | Point to the new location of g++:
   .. code-block:: bash

    export PATH=$HOME/.local/bin:PATH

   | *Note*: if you'll need this often then add to your .bashrc file
   | Check that it worked:
   .. code-block:: bash

    which g++
    cmi -a

   | Both should now recognize the new compiler.

#. | Make the OpticalCoupling_Recombination file:
   .. code-block:: bash

    export STROOT=/CMC/tools/synopsys/sentaurus_vS_2021.06/

   | *Note*: or set in Makefile. Needed in order to find the proper header files
   | The makefile is typically stored in the /pmi/src folder.
   .. code-block:: bash

    cd ./path/to/makefile
    make

   | The file should now be properly compiled.

Running
----------------------------------

There are a few different ways to run the program: from within a Python IDE, using Python from the command line, using a Python node from within Sentaurus, or using a TCL script from within Sentaurus.

Since the program was written to work with Sentaurus in mind if you are running from an external Python environment you will need to set `run_cmdline = True` and set `epi_node`, `sde_node`, and `MatPar_node` manually. If you are running from within a Sentaurus Python environment then set `run_method = Sentaurus` amd the necessary values should be filled automatically. If you are running from an IDE then `epi_node`, `sde_node`, and `MatPar_node` will ned to be set manually at the top of the script. If you are running from either the command line directly or using a TCL script within Sentaurus then the values are set using system arguments:

.. code-block:: console

  /path/to/python/env/bin/python3 /path/to/LCMatrix_pyt.py LC_filename epi_node sde_node MatPar_node wtot substrate_t True > /path/to/output_file.txt
