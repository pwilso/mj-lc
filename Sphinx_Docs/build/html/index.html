Welcome to MJ-LC’s documentation!¶

MJ-LC (MultiJunction Luminescent Coupling) calculates the relationship between an emission event at a given location in a layered semiconducting structure and an absorption event at some other location within that structure. The matrix relating all emission and absorption events as a function of position can be imported into other tools to generate the generation rate due to radiative recombination events anywhere in the device. This project was designed to work with device simulations in Synopsys Sentaurus and tools and descriptions are described related to this software. In principle though, the matrix generated by MJ-LC can be adapted for use by other programs.
