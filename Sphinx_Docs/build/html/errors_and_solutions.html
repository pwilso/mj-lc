Common Errors and Possible Solutions¶

Error when compiling changed Cython files for the first time through Sentaurus.

Message:

The first time you run the program (or if you changed anything in the Cython files) it may throw some warnings which are ignored when running in the terminal but cause Sentaurus to exit with an error.

The error will look like a compiler error (something with “gcc” in the error message).

Solution:

pip3 install Cython
cythonize path/to/Python/tmm/tmm_core_mw.pyx

This ensures that tmm_core_mw.pyx has been properly updated/compiled.

Next, open a python terminal.

import os
import sys
sys.path.append(os.path.join(os.path.dirname(os.path.abspath(file)), '..', 'Python')) # may need to adjust depending on your cwd
sys.path.append(os.path.join(os.path.dirname(os.path.abspath(file)), '..', 'Python', 'tmm'))
import pyximport; pyximport.install()
import epi_cmd_LC
import tmm.tmm_core_mw as tmm

You’ll recognize this as just the first block of the LCMatrix.py script. Running through a Python terminal first allows messages generated by the compiler to be ignored. Subsequent runs will not generated these messages allowing the Sentaurus program to proceed.


Error when trying to run a LCMatrix.py file that previously compiled fine.

Message:

epi_cmd_LC.c:1:2: error: #error Do not use this file, it is the result of a failed Cython compilation.
#error Do not use this file, it is the result of a failed Cython compilation.

DistutilsExecError: command 'gcc' failed with exit status 1

CompileError: command 'gcc' failed with exit status 1

ImportError: Building module epi_cmd_LC failed: ["distutils.errors.CompileError: command 'gcc' failed with exit status 1\n"]

Solution:

If running cythonize on epi_cmd_LC.pyx does not generate any messages then attempt to “wake-up” the compiler by adding a small change to the beginning of the file.

For example, add the variable test_change = 1 at the beginning of the file.

Rerun cythonize on the .pyx file. It will hopefully generate outputs and recompile the file fully now.
